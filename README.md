**This Magento 2 module is an add-on package to the LokiCheckout.**

## Further recommendations
We strongly recommend installing the additional package `loki-checkout/magento2-hyva-skinny` to optimize your theme within the checkout.

## Installation
Install this package via composer:
```bash
composer require loki-checkout/magento2-hyva
```

Next, enable this module:
```bash
bin/magento module:enable LokiCheckout_Hyva
```
