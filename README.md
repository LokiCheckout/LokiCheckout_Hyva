# Yireo_LokiCheckoutHyva

**This is an add-on package to the LokiCheckout. It is only a dummy to kickstart new modules easily.**

## Further recommendations
We strongly recommend installing the additional package `yireo/magento2-loki-checkout-hyva-skinny` to optimize your theme within the checkout.

## Installation
Install this package via composer (assuming you have setup the `composer.yireo.com` repository correctly already):
```bash
composer require yireo/magento2-loki-checkout-hyva
```

Next, enable this module:
```bash
bin/magento module:enable Yireo_LokiCheckoutHyva
```
